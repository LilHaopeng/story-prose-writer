# 正文产物契约与上下游接口

初始化、撰写或审校小说正文时读取。本契约定义了与 `story-world-architect`、`story-outline-architect` 协同工作的推荐结构；遇到已有自定义目录或非标准命名的项目时，先做只读识别并建立来源映射，直接适配现有文件。

## 1. 推荐目录结构与职责边界

```text
{项目根}/
├── 设定/
│   └── 世界观/
│       ├── 00_创作锚点.md             # 只读锚点：基准时间、基调、货币尺度
│       ├── 01_硬规则.md               # 只读约束：RULE-NNN
│       ├── 08_社会阶层与文化.md       # 礼俗、称谓、日常生活肌理
│       ├── 14_当前世界状态.md          # 只读基线：WS-NNN
│       └── 15_大纲接口.md             # 只读契约：信息边界、禁用假设、语言与日常肌理切片
├── 大纲/
│   ├── 工作状态.md                    # 大纲进度与锁定版本
│   ├── 世界观引用.md                  # 本书选用的 RULE/CON/SEED 与语言肌理参考
│   ├── 00_故事DNA.md                  # L0：创作初衷、期待场面、类型承诺、主导驱动力
│   ├── 01_故事架构.md                 # L1：人物决策依据、关系张力与五轨
│   ├── 故事弧/ARC-*.md                # L2：阶段目标与不可逆变化
│   ├── 剧情段/SEQ-*.md                # L3：局部驱动问题与开篇窗口
│   ├── 细纲_第001章.md                # L4：单章事件、选择代价、节奏类型、可选戏眼
│   └── 场景/CH-001_SC-01_名称.md      # L5：复杂场景博弈蓝图（按需）
├── 追踪/
│   ├── 章节交接.md                    # 正文维护：跨章状态、伤势道具、起收镜头、末尾原文
│   ├── 角色状态.md                    # 协同维护：人物当前认知、关系、资源、伤病
│   ├── 伏笔.md                        # 协同维护：Setup / Reinforcement / Payoff
│   ├── 信息与反转.md                  # 防剧透红线：读者知道 vs 主角知道 vs 对手知道
│   ├── 未闭环.md                      # 故事义务追踪：LOOP-NNN
│   └── 世界状态变化.md                # 拟议变化在正文实际发生后更新为 verified
├── 正文/
│   ├── 写作状态.md                    # 写作语言、字数档位、已完成章节、累计净字数
│   ├── 00_文风与声口卡.md             # 风格参数、定调原声切片（必读调音叉）与角色声口表
│   ├── 试写/
│   │   └── 试写_v1_文风名.md          # 开书试写或风格对照样本
│   ├── 第001章_章名.md                # 正式章节正文（纯小说文本，无任何工程标签）
│   └── 版本/                          # 定稿快照
└── 交付/
    └── {项目名}_小说正文_{范围}_{版本}.docx
```

## 2. 上下游所有权约定

| 资产类型 | 权威所有者 | 正文技能（Prose Writer）权限与协同规则 |
|---|---|---|
| 世界硬规则、制度、势力与语言肌理（`RULE/INST/FAC`） | `story-world-architect` | **只读遵循与生活化调用**。吸收世界观中的称谓、器物与日常规矩；不私造未登记的规则豁免或超模设定，需突破时发起 `WCR-NNN` 交用户确认。 |
| 故事主线、章纲目标与选择代价（`ARC/SEQ/CH`） | `story-outline-architect` | **消融执行与联动缩放**。将章纲因果自然消融进具体场景；扩缩篇幅需调整锁定章纲时，经用户确认后同步更新。 |
| 写作语言、声口卡、正文文本、章节交接卡 | `story-prose-writer` | **权威维护**。保持章节文件纯净无元信息污染，维护原声锚点与跨章交接连贯。 |
| 角色状态、伏笔状态、世界状态变化验证 | 大纲与正文协同 | 依据正文已发生的事实回写既有台账；世界状态变化仅在正文确有发生且对应既有条目时从 `planned` 更新为 `verified`。 |

## 3. 核心文件模板

### 3.1 `正文/写作状态.md`

```markdown
# 正文写作状态

- 项目名：
- 写作语言：简体中文（默认；可按用户要求切换为 English / 繁體中文 / 其他语言）
- 当前工作模式：estimate / audition / draft / revise / audit / deliver
- 绑定的大纲版本：v1.0 / draft
- 绑定的世界观版本：v1.0 / 无
- 字数配置档位：精简档 / 标准档 / 丰满档 / 自定义
- 单章目标规模：3000 - 3500 汉字（英文项目按 words 计，如 2500 - 3500 words）
- 全书预估总规模：
- 当前已锁定文风：见 `正文/00_文风与声口卡.md`（状态：confirmed / draft）
- 已完成章节：无 / CH-001 至 CH-NNN
- 当前累计净规模：0
- 下一待写章节：CH-001
- 待确认事项：
```

### 3.2 `正文/00_文风与声口卡.md`

```markdown
# 文风与声口卡

- 项目名：
- 状态：draft / confirmed
- 写作语言：简体中文
- 模式来源：预设流派组合 / 自定义流派检索解构 / 用户样稿提炼
- 基底与融合方向：如「冷硬白描派 + 市井烟火微调」
- 自定义流派参考与技法依据（注明可核验来源、用户材料或暂拟未核实）：
  - 参考来源：
  - 核心叙事技法：
- 叙事视角（POV）与信息边界：第一人称 / 第三人称限知 / 多视角 / 全知
- 叙述距离：贴身沉浸 / 半步平视 / 冷峻抽离
- 句法与页面呼吸节奏：长短段交替、裸对白连击留白、避免连续等高豆腐块段落
- 感官锚点与世界日常词表：每场精选 1–2 处核心感官；记录本作常用称谓、器物与行话
- 本书修辞禁区与出戏词：禁止直接照搬技能示例动作、严控碎引号与句尾解释尾巴

## 定调原声切片（Voice Tuning Fork · 每次动笔必读）

> 在此粘贴 150–250 字经用户认可的本书试写或标杆段落，锁死叙述语调、句长弹性与留白手感：
>
> （待试写确认后填入原文切片）

## 核心角色声口表（Voice Matrix）

| 角色名 | 身份与性格底色 | 句式与用词特征 | 潜台词与防御习惯 | 代表性原声台词（1–2 句真话样本） | 绝对不会说的话 |
|---|---|---|---|---|---|
```

### 3.3 `追踪/章节交接.md`

每完成一章追加一条交接记录，同时追踪跨章状态与镜头变化：

```markdown
# 章节交接台账

## CH-001 -> CH-002 交接卡

- 上一章定稿文件：`正文/第001章_章名.md`
- 实际净字数：3280 字
- 结束时间与地点：入夜子时，旧港三号货仓外栈桥（雨刚停，积水结薄冰）
- 本章起收镜头：算盘账目特写切入 → 双人对白未答截断收尾（下一章请错开切入与收束方式）
- 在场角色与精确状态：
  - 主角：左掌铁丝划痕未包扎，怀揣半本泡水账册，表面平静但体力透支
  - 配角：巡夜班头站在十步外点旱烟等解释，已起疑尚未翻脸
- 刚落地的因果新状态（New State）：主角放弃毁账（Choice），代价是被班头堵个正着（Cost）
- 本章新增/推进伏笔：`F-001`（账册缺页去向，已埋设）
- 信息边界提醒：主角此时**尚不知道**班头是幕后掌柜的亲侄子（严禁在 CH-002 旁白漏底）
- 章末原文摘录（1–3 句）：
  > （摘录末尾原文供气息衔接参考；下一章可紧接或按章纲合理跳时）
- 下一章（CH-002）切入抓手：
```

### 3.4 章节正文文件（`正文/第001章_章名.md`）

章节文件保持绝对纯净，只含章标题与小说正文（场景切换可用空行或居中 `* * *`），不混入任何工程编号、字数统计或自检说明：

```markdown
# 第001章 章名

正文第一段……

正文第二段……
```
