# 正文产物契约与上下游接口

初始化、撰写或审校小说正文时读取。本契约描述与 `story-world-architect`、`story-outline-architect` 的推荐接口；实际项目可能使用其他路径或只有部分台账，须先做只读发现，不能假定已无缝接入。

## 1. 目录结构与职责边界

```text
{项目根}/
├── 设定/
│   └── 世界观/
│       ├── 01_硬规则.md               # 只读约束：RULE-NNN
│       ├── 14_当前世界状态.md          # 只读基线：WS-NNN
│       └── 15_大纲接口.md             # 只读契约：信息边界与禁止假设
├── 大纲/
│   ├── 工作状态.md                    # 大纲进度与锁定版本
│   ├── 世界观引用.md                  # 本书选用的 RULE/CON/SEED
│   ├── 00_故事DNA.md                  # L0：类型承诺、核心体验、主导驱动力
│   ├── 01_故事架构.md                 # L1：人物决策依据、关系张力与五轨
│   ├── 故事弧/ARC-*.md                # L2：阶段目标与不可逆变化
│   ├── 剧情段/SEQ-*.md                # L3：局部驱动问题与开篇黄金窗口
│   ├── 细纲_第001章.md                # L4：单章目标、冲突、选择、代价、戏眼、钩子
│   └── 场景/CH-001_SC-01_名称.md      # L5：复杂场景博弈蓝图（按需）
├── 追踪/
│   ├── 章节交接.md                    # 正文维护：跨章即时状态、位置、伤势、物品、钩子衔接

│   ├── 伏笔.md                        # 正文与大纲共建：Setup / Reinforcement / Payoff 落点
│   ├── 信息与反转.md                  # 防剧透红线：读者知道 vs 主角知道 vs 对手知道

├── 正文/

│   ├── 试写/
│   │   └── 试写_v1_文风名.md          # 开书定调或局部试写样本

│   └── 版本/                          # 定稿快照
└── 交付/
    └── {项目名}_小说正文_{范围}_{版本}.docx
```

## 项目体检与兼容层（写前）

1. 只读识别现有目录、文件、已确认版本和可用材料；支持用户提供的等价结构化大纲与世界观资料，不因为没有标准文件名就认定资料不存在。列出识别结果和本章所用来源，含不确定的对应关系。
2. 本章需要可读的章纲或用户提供的等价剧情安排；涉及的关键世界规则、人物状态和信息边界必须有足够依据。关键材料缺失且会影响判断时，明确列出缺口，询问或等待材料；其他不依赖缺口的工作可继续。禁止把“未记录”当作“无规则/无伏笔/可公开”。
3. `角色状态.md`、`伏笔.md`、`信息与反转.md`、`未闭环.md` 和世界变化表可按项目需要存在，不强制预先建齐。缺失时从实际存在的大纲、设定和前文提取有出处的临时摘要，未知项显式标记，不能推测秘密已公开或补造正典。
4. 写后台账优先沿用原有路径、字段和状态语义；新增条目注明正文证据，不覆盖上游既有内容。世界变化仅在正文确有发生且能对应已有变化项时才由 `planned` 更新为 `verified`；不存在或不适用时不凭空创建既定变化。

## 2. 上下游所有权铁律

| 资产类型 | 权威所有者 | 正文技能（Prose Writer）权限与义务 |
|---|---|---|
| 世界硬规则、制度、势力（`RULE/INST/FAC`） | `story-world-architect` | **严格只读遵循**。不得在正文中发明未登记的规则豁免、超模道具或跨地域管辖漏洞；若需突破，先停笔并发起 `WCR-NNN`。 |
| 故事主线、章纲目标与选择代价（`ARC/SEQ/CH`） | `story-outline-architect` | **受控执行与联动缩放**。按章纲的 `Goal -> Conflict -> Choice -> Cost -> New State` 行文；字数缩放需改章纲时，核对既有授权，需要时先取得用户确认再同步修改。 |
| 文风参数、角色声口、正文文本、章节交接卡 | `story-prose-writer` | **权威维护**。确保章节内部纯文本无元标签污染，所有元数据与连续性台账写入 `正文/写作状态.md` 与 `追踪/章节交接.md`。 |
| 角色状态、伏笔状态、世界状态变化验证 | 大纲与正文协同 | 按需更新现有路径及字段：伏笔埋设和回收沿用项目状态语义；仅有证据且对应已有变化项时记录世界状态变化落地。缺少可选台账时，不强制新建全部文件。 |

## 3. 核心文件模板

### 3.1 `正文/写作状态.md`

```markdown
# 正文写作状态

- 项目名：
- 当前工作模式：estimate / audition / draft / revise / audit / deliver
- 绑定的大纲版本：v1.0 / draft
- 绑定的世界观版本：v1.0 / 无
- 字数配置档位：精简档 / 标准档 / 丰满档 / 自定义
- 单章目标字数区间：3000 - 3500 字
- 全书预估总字数：
- 当前已锁定文风：见 `正文/00_文风与声口卡.md`（状态：confirmed / pending）
- 已完成章节：无 / CH-001 至 CH-NNN
- 当前累计净字数：0
- 下一待写章节：CH-001
- 待确认事项：
```

### 3.2 `正文/00_文风与声口卡.md`

```markdown
# 文风与声口卡

- 状态：draft / confirmed
- 模式来源：预设八大流派 / 自定义流派（联网资料、用户提供材料或明确标注未验证的方案）
- 基底流派：如「冷硬白描派 + 悬疑心理微调」或用户自定义流派名
- 自定义流派依据与核心手法提炼（注明可核验的链接、用户材料或未验证）：
  - 对标参考与来源链接：
  - 提炼的核心叙事技法：
- 叙事视角（POV）：按用户和大纲确定第一人称、第三人称限知、多视角或全知；尊重已选视角的信息边界
- 叙述距离：贴身沉浸 / 半步观察 / 冷峻抽离
- 句长与段落规范：
  - 日常与铺垫句长、分段节奏：按作品及场景确定，以下任何数字仅供参考
  - 冲突与危机句长：可用短句提速，也可依作品需要变化
  - 段落长度：按阅读节奏与排版审视，不设统一硬上限
- 感官锚点偏好：优先调动触觉（温度/痛感/材质）、听觉（环境底噪/动作声）与器物细节，少用空泛视觉形容词
- 对白与叙述配比：依题材和场景选择，不设统一比例或纯对白行数上限
- 本书专属用词偏好或用户明确指定的限制（通用套话表仅作候选检查）：

## 核心角色声口表（Voice Matrix）

| 角色名 | 身份与性格底色 | 句式与用词习惯 | 潜台词与情绪防御机制 | 标志性小动作/口头禅（克制使用） | 绝对不会说的话 |
|---|---|---|---|---|---|
```

### 3.3 `追踪/章节交接.md`

解决跨章“失忆”、场景瞬移和情绪断层的核心台账。每写完一章追加一条记录：

```markdown
# 章节交接台账

## CH-001 -> CH-002 交接卡

- 上一章定稿文件：`正文/第001章_章名.md`
- 实际净字数：3280 字
- 结束时间与地点：入夜子时，旧港三号货仓外栈桥（雨刚停，地面积水结薄冰）
- 在场角色与精确状态：
  - 主角：左手掌心被铁丝划破（未包扎），体力透支，怀里揣着半本泡水的账册，情绪处于惊疑后的强行镇定
  - 对手/配角：巡夜班头已起疑但尚未翻脸，正站在十步外点烟等解释
- 刚完成的章纲果（New State）：主角放弃销毁账册（Choice），代价是被巡夜班头堵在现场（Cost）
- 本章新增/推进伏笔：`F-001`（账册缺页去向，已埋设）
- 信息边界提醒：主角此时只知道账册属于漕帮，**尚不知道**班头是幕后黑手的亲侄子（严禁在 CH-002 旁白中写破）
- 章末最后三行原文摘录：
  > （摘录最后 1–3 句或有上下文意义的结尾片段，注明摘录范围；供衔接参考，不强制下一章紧接上一句）

- 下一章（CH-002）切入抓手：按下一章章纲决定是否接续盘问或合理跳时。
```

### 3.4 章节正文文件（`正文/第001章_章名.md`）

章节文件必须保持纯净，只包含标题与小说正文，**不得在章节文件内混入大纲分析、字数统计、修改说明或自检报告**（报告在对话中展示或写入台账）：

```markdown
# 第001章 章名

正文第一段……

正文第二段……
```
