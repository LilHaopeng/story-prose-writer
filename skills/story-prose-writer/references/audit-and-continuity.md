# 正典守恒、六维审校与双端 DOCX 交付规范

在每章初稿完成后、执行 `audit / revise` 时或将正文汇编为 `.docx` 文档时读取。

## 1. 正典与因果守恒四原则

1. **核心设定有据可依**：货币面额、官职品级、地理里程、力量/技术代价与机构名称遵循已确认的世界观与大纲；日常饮食、普通铺面与市井闲谈可在创作锚点与语言肌理范围内自然发挥，不随手发明会改变规则边界的核心专有名词或跨级特权。
2. **因果落点扎实（兼顾消融与留白）**：章纲确定的核心目标、取舍、代价与新状态须在场景中真实落地（不抢写下章冲突，也不漏掉关键信息），但应藏入具体行动与对话中，允许余波留白章放缓外部冲突节奏。
3. **代价留痕**：大纲与 `RULE-NNN` 规定的损耗、伤势、欠债或人情代价必须在人物后续动作与处境中留下真实痕迹，不搞“上章重伤吐血、下章健步如飞”。
4. **冲突先沟通**：发现章纲预设动作与世界硬规则抵触时（如里程与交通速度矛盾），先列出冲突依据并提供“调整时序”或“补充前置条件/发起变更”选项请用户拍板，不私造一次性外挂圆场。

## 2. 交稿前六维审校表（6-Dimension Prose Audit）

| 维度 | 核心核对问题 | 严重度 | 修订动作 |
|---|---|---|---|
| **D1 因果与消融** | 本章核心变化是否完整兑现？是否做到了“表层日常包裹底层算计”，而非机械背诵大纲字段？ | **S0 阻断** | 补齐缺失因果，或将直白的大纲总结改写为具体场景交互 |
| **D2 世界观与老手视角** | 是否严守 `RULE/INST` 边界与购买力尺度？是否避免了借土著角色内心给读者写“制度科普说明书”？ | **S0 阻断** | 修正违规设定；删去科普式独白，改为角色遇到摩擦时的自然反应 |
| **D3 跨章连续性** | 与上章 `章节交接.md` 的时间、地点、天气、伤势、持有物是否咬合？起收镜头是否主动错开？ | **S1 严重** | 修补场景衔接、补上伤势/道具的延续反应，替换雷同开篇句式 |
| **D4 视角与信息边界** | 是否严守已选 POV？限知视角有无写到角色看不见的表情或提前泄露远期反转？ | **S1 严重** | 将越界全知信息改写为可观察的外部痕迹与主观推测 |
| **D5 人物化学反应与声口** | 遮住名字能否听出是谁的台词？配角与对手是否有自己的算计与底线？ | **S2 中度** | 对照声口卡中的“原声台词样本”重写同质化对白，补足对手合理反应 |
| **D6 母语语感与页面观感** | 复核 `lint_prose.py` 报告：有无高频词复读、连续等高豆腐块段落、句尾解释尾巴、碎引号泛滥或代词过密？ | **S2 中度** | 拆分密集长块，增补裸对白留白，省去冗余代词与强调引号 |

## 3. 写后状态回写清单（Post-Chapter Ledger Sync）

正文定稿后，依据**本章正文实际已发生的事实**更新项目现有台账（保留既有字段语义，不把尚未发生的远期计划提前标为已完成）：

1. **`追踪/章节交接.md`**：追加本章交接卡，记录章末时空、人物伤势与物品、本章起收镜头类型、信息边界提醒及章末 1–3 句原文。
2. **`追踪/角色状态.md`**：更新出场角色的位置、伤病、资源增减与关系位移。
3. **`追踪/伏笔.md` 与 `追踪/未闭环.md`**：登记新埋线索（`active`）或将已兑现条目更新为 `resolved（第XXX章）`。
4. **`追踪/世界状态变化.md`（若有）**：本章已落地且对应既有 `Change ID` 的世界变化，由 `planned` 更新为 `verified（第XXX章）`。
5. **`正文/写作状态.md`**：更新已完成章节、累计净字数（英文记 words）与下一待写章节。

## 4. DOCX 汇编与双端视觉排版规范

导出 Word 阅读稿时，默认输出至 `交付/{项目名}_小说正文_{范围}_{版本}.docx`，确保正文中绝无 `RULE-001`、`CH-001`、`[待确认]` 等内部工程痕迹。

可直接使用配套脚本构建干净的小说排版文档（需安装 `python-docx`）：

```text
# 实体书沉浸排版（默认：宋体/Georgia 衬线正文、首行缩进、紧凑行气、居中星号转场）
python <skill-dir>/scripts/build_prose_docx.py --chapters-dir <正文目录> --out <输出.docx> --title <书名> --preset book

# 屏幕/连载轻读排版（无首行缩进、舒展段距、现代清爽观感）
python <skill-dir>/scripts/build_prose_docx.py --chapters-dir <正文目录> --out <输出.docx> --title <书名> --preset screen
```

- **双端观感分流**：
  - **`book`（实体书沉浸版）**：中文采用宋体（11.5pt）配微软雅黑章标题，首行缩进 2 字符，行距 1.48 倍，段后微距 1.5pt（避免“首行缩进 + 大段距”造成的版面松散割裂）；英文自动切换为 `Georgia`（11pt）配 `0.28 in` 首行缩进。支持 `--page-size a4|b5|a5`。
  - **`screen`（屏幕轻读版）**：取消首行缩进，段后留白 7pt，适合平板、电脑与移动端审读。
- **视觉核验**：环境具备 LibreOffice 与 PDF 渲染库时，转出 PDF 检查分页、页眉页脚与章末留白，确认美观无乱码后交付。
